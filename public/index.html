📜 Rule ၃ ခုတည်း

  1. Ticket ကို code ရေးပြီး တခြားတစ်ယောက်က test လုပ်ပေးရင် ပြီးတယ်
  2. သောကြာ နေ့လယ်မှာ အားလုံး တစ်ပြိုင်နက် Deploy လုပ်ရမယ်
  3. ကြားထဲမှာ သစ္စာဖောက် တစ်ယောက် ရှိတယ် — ဘယ်သူလဲ ရှာပြီး မဲပေးပါ

🏆 ဘယ်လိုနိုင်မလဲ

သင်ကနိုင်ဖို့
👷 ပုံမှန် ဝန်ထမ်းအဖွဲ့ Ship ဖြစ်ရင် နိုင်တယ်
🕵️ သစ္စာဖောက် (Job Hunter)အဖွဲ့ Ship မဖြစ်ရင် နိုင်တယ်

Ship ဖြစ်တယ် = ① သောကြာ Deploy အောင်မြင် + ② Ticket ၄၀% အထက် ပြီး
❌ Client ကျေနပ်မှု 😊 0 ကျသွားရင် ချက်ချင်း ရှုံးတယ်

🕵️ သစ္စာဖောက်ကို ရှာနည်း

သစ္စာဖောက်က F နဲ့ ticket ထဲ bug ထည့်တယ် · Deploy အချိန် server ကြိုးဖြုတ်တယ်
လုပ်တိုင်း #git-log မှာ သဲလွန်စ (🔴🔵🟢 အရောင် ဒါမှမဟုတ် 🧙🐣 role) ပေါ်တယ်
🗳️ နေ့လယ်တိုင်း မဲပေးမယ်: မဲ ၂ မဲ ရသူကို ဖမ်းမယ် → သစ္စာဖောက်ဆိုရင် 🎉 sabotage မလုပ်နိုင်တော့ · မှားဖမ်းရင် 😬 အဲဒီလူ မနက်ဖြန်အထိ ability ပိတ်

⚠️ အရေးပေါ်
